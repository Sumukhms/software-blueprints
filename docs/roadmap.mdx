# 🗺️ Project Roadmap & Work Division

If you are a collaborator, please claim a task from the **"To Do"** lists below. Once you start working on it, update the status, and follow the guidelines in `CONTRIBUTING.md`.

## 🚀 How to Contribute

1. **Claim a Task:** Pick any component or blueprint that is marked as `🔴 To Do`. 
2. **Assign Yourself:** Submit a PR updating this file with your name in the `Assignee` column and changing the status to `🟡 In Progress`.
3. **Build:** Follow the strict rules in `CONTRIBUTING.md` (Semantic HTML, Accessibility, Mobile Responsiveness, Keyboard Navigation).
4. **Submit PR:** Open a Pull Request for code review!
