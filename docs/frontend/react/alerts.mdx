# Alerts & Notifications

Accessible, highly visible alert components designed with explicit ARIA roles (`role="alert"` or `role="status"`) to ensure immediate screen reader notification.

```jsx
export default function StandardAlert() {
  return (
    <div className="alert-container">
      {/* role="status" for non-critical, polite updates */}
      <div className="alert-std success" role="status" aria-live="polite">
        <div className="alert-icon" aria-hidden="true">✓</div>
        <div className="alert-content">
          <h4>Update successful</h4>
          <p>Your profile has been updated successfully.</p>
        </div>
      </div>

      {/* role="alert" for immediate, critical errors */}
      <div className="alert-std danger" role="alert">
        <div className="alert-icon" aria-hidden="true">!</div>
        <div className="alert-content">
          <h4>Payment failed</h4>
          <p>Please check your credit card details and try again.</p>
        </div>
      </div>
    </div>
  );
}
```
