# Data Tables

Enterprise-grade table components emphasizing responsive design (mobile scrolling), clear data hierarchy, and accessibility (`aria-labels`, `scope`).

```jsx
export default function StandardTable() {
  return (
    {/* wrapper allows horizontal scrolling on mobile */}
    <div className="table-wrapper" tabIndex="0" aria-label="Standard Data Table">
      <table className="table-std">
        <thead>
          <tr>
            {/* scope="col" helps screen readers understand headers */}
            <th scope="col">Name</th>
            <th scope="col">Role</th>
            <th scope="col">Status</th>
          </tr>
        </thead>
        <tbody>
          <tr>
            <td>Jane Doe</td>
            <td>Admin</td>
            <td><span className="status-active">Active</span></td>
          </tr>
          <tr>
            <td>John Smith</td>
            <td>Editor</td>
            <td><span className="status-offline">Offline</span></td>
          </tr>
        </tbody>
      </table>
    </div>
  );
}
```
