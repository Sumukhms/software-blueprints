# Live UI Templates

When designing software blueprints, you can embed fully interactive UI templates right inside the documentation. Below are some examples showing both the React component and the CSS styling executing live.

Try editing the CSS inside the `style` tags or the inline styles below to see the preview update instantly!

## 1. Premium Pricing Card

## 2. Modern Login Form

```jsx live
function LoginForm() {
  return (
    <div style={{ fontFamily: 'system-ui, sans-serif', padding: '20px' }}>
      <style>
        {`
          .login-container {
            background: white;
            padding: 30px;
            border-radius: 12px;
            box-shadow: 0 4px 20px rgba(0,0,0,0.1);
            max-width: 350px;
            color: #333;
          }
          .input-group {
            margin-bottom: 15px;
          }
          .input-group label {
            display: block;
            margin-bottom: 5px;
            font-size: 0.9rem;
            font-weight: 600;
            color: #555;
          }
          .input-group input {
            width: 100%;
            padding: 10px;
            border: 1px solid #ddd;
            border-radius: 6px;
            font-size: 1rem;
            box-sizing: border-box;
            transition: border-color 0.3s;
          }
          .input-group input:focus {
            outline: none;
            border-color: #6366f1;
            box-shadow: 0 0 0 3px rgba(99, 102, 241, 0.2);
          }
          .submit-btn {

            color: white;

            padding: 12px;

            font-size: 1rem;
            font-weight: bold;

      </div>

  );
```
